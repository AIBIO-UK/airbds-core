# AIRBDS core

This is the repository for the [AIRBDS machine-readable metrics YAML file](airbds_metric.yaml), and a skill for making AIRBDS assessments via AI assistants.

Please see [`skills/README.md`](skills/README.md) for instructions on installing and using the skill.

Please see the AIRBDS assessment paper for more information on the metric itself.

Please see the [airbds-dev repository](https://github.com/AIBIO-UK/airbds-dev) for versions of the skill and metric in development, as well as other tooling.
